# 1. 국내 고형제 제조업체가 규정 준수를 위해 봐야 하는 문서

> 목적: "특정 공정 종료 후 수율 저하"가 탐지됐을 때 공정 엔지니어가 **무엇을 해야 하고 무엇을 지켜야 하는지** 판단하는 근거 문서를 정리한다.
> ✅ = 이 데모 색인에 포함(국가법령정보센터에서 자동 수집), ⬜ = 미포함(아래 사유)

|---|---|---|---|---|

- 한국은 2014년 PIC/S 에 가입했고, 고시 「의약품 제조 및 품질관리에 관한 규정」의 별표 구성(무균, 컴퓨터화 시스템, 적격성평가와 밸리데이션, 완제의약품 제조 등)은 PIC/S GMP Annex 체계를 따른다.
- KGMP 자체가 회사에 **기준서(제조관리기준서·품질관리기준서 등)** 작성을 요구하므로, 실제 조치 기한·양식은 **사내 SOP** 가 정한다. 에이전트는 법령·고시가 요구하는 "무엇"을 알려주고, "언제까지·어떤 양식"은 사내 SOP 로 넘겨야 한다.

## 1.4 자동 수집하지 못한 문서와 추가 방법

식약처 누리집(mfds.go.kr, nedrug.mfds.go.kr, nifds.go.kr)은 이 실험 환경(해외 클라우드)에서 TLS 연결이 끊겨 받을 수 없었다(국내 IP 에서는 정상 접속).
아래 유형의 문서를 국내에서 내려받아 `data/raw/user_docs/` 에 넣고 `uv run kgmp ingest` 를 실행하면 kordoc 으로 파싱해 **위계 5(가이드라인)** 로 색인한다.

- 일탈 관리, 공정 밸리데이션, 품질위험관리(ICH Q9), 변경관리, 제품품질평가, 데이터 완전성 관련 가이드라인·민원인 안내서
  (정확한 제목·최신판은 식약처 "법령/자료 > 공무원지침서·민원인안내서" 목록에서 확인 — 이 문서의 제목 예시는 접속 불가로 검증하지 못했음)
- PIC/S GMP Guide PE 009 Part I, Annex 15 (PDF)
- 회사 SOP (일탈·CAPA·변경관리) — 사내 문서까지 넣으면 "언제까지·어떤 양식"까지 안내할 수 있다
